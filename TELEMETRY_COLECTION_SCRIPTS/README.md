# DATA COLLECTION
All data collection scripts have been put int their respective setup type. Note that Setup A is the DDR4 machine and Setup B is the DDR5 machine. The usage of PAMPAR benchmark suit, Intel PCM, and plundervolt helper scripts, TRRespass, and Spectre, scripts are used in parrellel to data collection. Each supporting bash script will need to be edited to ensure this may run on your machine.

The relative links to all other information to get data collection up and running can be found here:
* [PAMPAR](https://github.com/adrianomg/PAMPAR)
* [Intel PCM](https://github.com/intel/pcm)
* [Plundervolt](https://github.com/KitMurdock/plundervolt)
* [TRRespass](https://github.com/vusec/trrespass)
* [Spectre](https://gist.github.com/anonymous/99a72c9c1003f8ae0707b4927ec1bd8a)

Please cite these related works if you use these techniques for your data collection.
