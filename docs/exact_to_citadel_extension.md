# EXACT To CITADEL Extension Map

This document separates the conference-version EXACT baseline from the TCAD-oriented CITADEL extension.

## Provenance

- Upstream method repo: `https://github.com/ping830616/EXACT`
- Default upstream commit recorded in CITADEL manifests: `b6b8b17ef825d9f4fad754f88c1de583b09805b9`
- CITADEL repo: `https://github.com/ping830616/CITADEL`
- Main experiment entry point: `notebooks/exact_tcad_all_experiments.ipynb`

The ETS baseline manifest is generated by the CITADEL notebook. It records the CITADEL git commit and an explicit `method_provenance.upstream_exact` entry so the paper can cite the inherited EXACT method without implying the notebook runs from a separate EXACT checkout.

To override the pinned upstream revision before launching Jupyter:

```text
export CITADEL_EXACT_REPO=https://github.com/ping830616/EXACT
export CITADEL_EXACT_REF=HEAD
export CITADEL_EXACT_COMMIT=<exact_commit_used_for_comparison>
```

## What EXACT Provides

| EXACT foundation | CITADEL use |
| --- | --- |
| Benign-only calibration | CITADEL keeps anomaly data out of calibration. |
| CINTAS/CIAS scoring | CITADEL reuses the score form as the runtime detector core. |
| Setup A and Setup B DDR telemetry flow | CITADEL keeps the same two hardware-counter platforms for continuity. |
| Workload/anomaly labels | CITADEL keeps the same workload and anomaly vocabulary for baseline comparison. |
| Causal feature ranking | CITADEL uses it as the starting point for compact telemetry selection. |
| Decision-block inference | CITADEL keeps windowed block decisions and expands the design sweep. |

## How To Frame The TCAD Story

1. **Start from EXACT:** reproduce the conference baseline under a manifest-controlled CITADEL run.
2. **Expose the baseline limits:** report that some anomaly/setup pairs are strong while DROOP is weak under the fixed baseline setting.
3. **Move to CITADEL:** use the TCAD sweep to search compact, hardware-aware detector settings instead of relying on one fixed baseline configuration.
4. **Add field practicality:** report FPR, calibration drift, and benign-only recalibration.
5. **Add deployment evidence:** attach fixed-point error, area/power estimates, and RTL golden vectors to the same selected configurations.

## Recommended Paper Language

Use wording like:

> CITADEL inherits the benign calibration, causal feature ranking, and CINTAS decision-block detector from EXACT. We first reproduce the EXACT-style baseline inside a manifest-controlled single-notebook workflow, then extend it with TCAD-oriented design-space exploration, false-positive-rate analysis, lifecycle recalibration, and hardware-cost/fixed-point validation.

Avoid wording that implies the ETS manifest is produced by a separate live execution of the upstream EXACT repository. It is a CITADEL manifest for a reproduced EXACT-style baseline.
